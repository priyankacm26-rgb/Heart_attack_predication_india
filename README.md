# ❤️ Heart Attack Analysis Using SQL

## 📌 Project Overview

Developed a SQL-based healthcare analytics project to analyze hospital patient data and identify key factors associated with heart attack risk. The project leverages SQL for data cleaning, exploratory analysis, KPI generation, trend identification, and risk-factor evaluation without using machine learning models.

The analysis focuses on transforming raw healthcare data into actionable insights that support data-driven healthcare decision-making.

---

## 🎯 Project Objective

The primary objective of this project was to:

* Analyze patient health records using SQL
* Identify major heart attack risk factors
* Generate healthcare KPIs and reports
* Explore relationships between medical attributes
* Support evidence-based healthcare analysis

---

## 📂 Dataset Details

**Dataset:** Hospital_Data.csv

* Age

* Chest Pain Type

* Fasting Blood Sugar
* Resting ECG
